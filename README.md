## Overview

CurveOps brings common operations work into a shared workspace for teams that need clearer coordination, better visibility, and consistent processes. By combining workflow organization with automation, it helps reduce tool switching and keeps day-to-day work moving.

The application is suited to operational, DevOps, and cloud infrastructure planning scenarios. Teams can manage tasks, review reports, and organize progress across Windows, macOS, and Linux environments.

## Capabilities

- Organizes operational workflows and routine work
- Helps automate repeatable activities

- Provides reports for reviewing performance
- Supports Windows, macOS, and Linux
- Uses an interface designed for regular daily operation
- Supports workflows related to DevOps and cloud infrastructure

## Getting Started

A standard CurveOps workflow can be organized as follows:

1. Launch CurveOps.
2. Add new tasks or import existing operational items.
3. Allocate resources and inspect the current workflow state.
4. Apply automation steps when they are relevant.
5. Use the reporting views to review activity and performance across time.

DevOps and cloud infrastructure teams can also use CurveOps to centralize operational tasks, delivery activities, and progress assessment.
